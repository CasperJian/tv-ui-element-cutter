# Contributing

Thanks for improving TV UI Element Cutter.

## Development

```bash
npm install
npm run dev
```

Before opening a pull request, run:

```bash
npm test
npm run build
```

## Pull Requests

- Keep changes scoped to the problem being solved.
- Add focused tests for detector behavior when changing image-processing logic.
- Include screenshots or short notes for visible UI changes.
- Avoid committing generated build output from `dist/`.
